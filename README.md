# Josh Jenkins Portfolio

Welcome to my personal portfolio website built with **React**, **TypeScript**, **Vite**, and **Material UI (MUI)**.
It showcases my projects, skills, and experience as a full-stack developer.

## Features

- Responsive layout using **MUI**
- Pages for **Home**, **Projects**, and **Contact**
- Highlighted projects:
  - **Stock Forecast ML** – LSTM model predicting stock prices
  - **Portfolio Website** – React + Vite portfolio
  - **NAVSEA Dashboard** – Internal dashboard project
- Hosted on **GitHub Pages**

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Material UI
- **Backend / API:** Node.js, PostgreSQL (used in projects)
- **Deployment:** GitHub Pages

## Getting Started

To run locally:

```bash
npm install
npm run dev
```

To build and deploy:

```bash
npm run build
npm run deploy
```
